# 🚀 Прототип Веб-интерфейса «Рабочее место менеджера»

> **Версия:** 1.0  
> **Статус:** Прототип (MVP)  
> **Стек:** Nuxt 4, Nuxt UI, Tailwind CSS, TypeScript

---

## 📖 О проекте

Сервис разрабатывается для **внутреннего использования** в сетевой торговой компании.  
Основная цель — создать единое «окно» для повседневных задач менеджеров и кладовщиков, заменив разрозненные инструменты (1С, сайт, корпоративный мессенджер).

### 🎯 Ключевые возможности

- ✅ Управление задачами филиала и личными заданиями
- ✅ Оформление предварительных продаж (корзина + заказ)
- ✅ Поиск и просмотр товаров в каталоге компании
- ✅ Централизованные уведомления о важных событиях
- ✅ Интуитивный и понятный интерфейс

---

## 🧩 Контекст и проблема

**Проблема:**  
Сотрудники вынуждены переключаться между 1С, сайтом и мессенджером, что замедляет работу и создает неудобства. Особенно критично это при:
- Оформлении покупки для клиента в зале
- Обработке входящих задач (уведомление → открыть → выполнить → закрыть в 1С)
- Проверке актуальности информации о товаре

**Решение:**  
Разработать единый веб-интерфейс, который объединит все эти сценарии в удобном и логичном виде.

## 🗺️ Структура страниц

| Страница               | Назначение |
|------------------------|------------|
| **Авторизация**        | Вход в систему |
| **Список задач**       | Все задачи филиала и личные задания |
| **Детальная задача**   | Просмотр и выполнение конкретной задачи |

| **Список товаров**     | Каталог с ID, названием, ценой и остатком |
